An ad-free, accessible, block-native slider for the WordPress block editor.

== Description ==

Kadenz Slider adds a slider block built on the Interactivity API. No ads, no upsells, no tracking, no external requests.

== Installation ==

1. Upload the plugin to `/wp-content/plugins/kadenz-slider`.
2. Activate it through the Plugins screen.
3. Insert the "Slider" block in the editor.
