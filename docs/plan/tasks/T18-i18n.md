# T18 – i18n & Übersetzungs-Pipeline

## Ziel

Das Plugin ist vollständig übersetzbar und wird mit einer deutschen Übersetzung (du und Sie) als Referenz
ausgeliefert, bis translate.wordpress.org übernimmt.

## Umfang (Dateien)

- `package.json` (Skript `i18n:pot`), `composer.json` (devDependency `wp-cli/i18n-command`, falls nicht via wp-env)
- `languages/kadenz-slider.pot`
- `languages/kadenz-slider-de_DE.po` und `-de_DE_formal.po` samt generierten `.mo`, `.l10n.php` und JSON-Dateien
- `.github/workflows/ci.yml` (Job `i18n-check`)
- `docs/i18n.md`

## Umsetzung

1. **String-Audit**: Alle UI-Strings in PHP und JS prüfen: korrekte Text-Domain, Übersetzer-Kommentare bei
   Platzhaltern, `_x` bei mehrdeutigen Begriffen („slide“ als Nomen und als Verb!), `_n` bei Pluralen
   (z. B. „%d slide“ / „%d slides“ im Editor).
2. **POT**: `wp i18n make-pot . languages/kadenz-slider.pot --exclude=node_modules,vendor,src,tests --headers='{"Report-Msgid-Bugs-To":"https://github.com/muka-dev/wordpress-slider-plugin/issues"}'`.
   Gescannt wird `build/` statt `src/`, weil die JS-Übersetzungen den Hash der Build-Dateien brauchen.
3. **JSON für Editor-Skripte**: `wp i18n make-json languages --no-purge`, danach `wp i18n make-php languages`
   (`.l10n.php`, ab WP 6.5).
4. **Laden**: Für wp.org-Plugins lädt WordPress Übersetzungen automatisch (Just-in-time). Für mitgelieferte
   Dateien `load_plugin_textdomain` **nicht** verwenden, sondern auf `languages/` per `Domain Path: /languages`
   im Header verweisen. Prüfen, ob das für 6.6+ noch nötig ist, und das Ergebnis in `docs/i18n.md` festhalten.
5. **CI-Job `i18n-check`**: generiert das POT neu und schlägt fehl, wenn es vom eingecheckten abweicht
   (Datums-Header ignorieren). So vergisst niemand ein Update.
6. **Deutsche Übersetzung**: vollständig, mit konsistenter Terminologie (Slide, Slider, Karussell,
   Paginierung → „Seitennavigation“). Ein Glossar steht in `docs/i18n.md`.

## Akzeptanzkriterien

- [ ] Mit `de_DE` als Sprache sind Editor-UI, Inspector, Variationen und Frontend-Ansagen (Status-Region,
  Pfeil-Labels, Toggle) deutsch.
- [ ] `i18n-check` ist grün, und ein absichtlich hinzugefügter String ohne POT-Update lässt ihn fehlschlagen.
- [ ] Plugin Check meldet keine i18n-Warnungen.

## Verifikation

```bash
npm run build && npm run i18n:pot && git diff --stat languages/
```
